Index of the four Hero progression Paths from [[How to Create a Hero]] step 2 & 6. Every HERO picks one Path on recruitment and cannot switch later — see each page for the full 4-tier ability tree (Aspiring → Elite → Mighty → Legendary).

## The Four Paths

| Path                    | Who can take it | Theme                                                     |
| ----------------------- | --------------- | --------------------------------------------------------- |
| [[Path of the Warrior]] | Anyone          | Melee upgrades, weapon mastery, personal durability       |
| [[Path of the Leader]]  | Anyone          | Command abilities, buffing the warband, objective control |
| [[Path of the Mage]]    | WIZARD only     | Bonus casting, extra spell-like abilities                 |
| [[Path of the Devout]]  | PRIEST only     | Bonus chanting, extra prayer-like abilities               |

## Shared Rank Structure

All four Paths use the same renown thresholds — see [[How to Create a Hero]] step 6:

| Rank | Renown | Grants |
|---|---|---|
| Aspiring | 5–14 | 1st Path ability (pick 1 of 2) |
| Elite | 15–29 | 2nd Path ability (pick 1 of 2) |
| Mighty | 30–44 | 3rd Path ability (pick 1 of 2) |
| Legendary | 45+ | 4th (final) Path ability — no further ranks |

At each rank-up, pick **one of the two listed options** for that tier. Both options at a tier are always available regardless of which options were picked at earlier tiers — the choice isn't gated, so across a full campaign a Hero ends up with exactly 4 abilities (one per tier). Log the picks on your army's Path Abilities table.

## Non-Hero Equivalents

Regular (non-HERO) units follow **Path of the Defender** or **Path of the Attacker** instead — same rank thresholds, different ability pool. Not covered here since this index is Hero-focused; ask if you want those built out too.
