*HERO only · anyone can take it.* Turns a Hero into a warband commander — command points, rally buffs, and objective control culminating in Ward or army-wide control bonuses. See [[Hero Paths]] for the shared rank structure and [[How to Create a Hero]] for the wider campaign rules.

## Rank Tree

| Rank | Renown | Option A | Option B |
|---|---|---|---|
| Aspiring | 5–14 | Tactical Acumen | Conserved Strength |
| Elite | 15–29 | Masterful Commander | Rousing Orator |
| Mighty | 30–44 | Defender of the Realm | Hardy Constitution |
| Legendary | 45+ | Destined for Greatness | Inspiring Leader |

## Aspiring (5–14 Renown)

**Tactical Acumen** — A friendly unit within 12" of this HERO can use the Redeploy command ability for free.

**Conserved Strength** — Heal (1) this HERO at the end of each turn.

## Elite (15–29 Renown)

**Masterful Commander** — At the start of the battle round, roll a dice. On a 4+, you gain 1 command point.

**Rousing Orator** — Add 1 to rally rolls for friendly units wholly within 12" of this HERO.

## Mighty (30–44 Renown)

**Defender of the Realm** — This HERO has STRIKE-FIRST while wholly within friendly territory.

**Hardy Constitution** — Add 2 to the Health characteristic of this HERO.

## Legendary (45+ Renown)

**Destined for Greatness** — This HERO has WARD (4+).

**Inspiring Leader** — Add 3 to the control scores of other friendly units contesting the same objective as this HERO.
